# XYZETON Album Backup（Windows用）

![Before / After](docs/images/before-after.png)

iPhoneの写真アプリで作ったアルバムの分け方を、そのままWindowsのフォルダとして保存します。
Backs up your iPhone photos to Windows, keeping your album structure as folders.

Get the latest zip from **Releases** on the right.
